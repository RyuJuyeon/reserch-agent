# 처음 사용하는 분을 위한 안내

이 저장소는 연구계획서 에이전트의 지침과 수정 기록을 보관하는 공간입니다. 아래 링크를 누르면 원하는 파일로 바로 이동합니다.

## 1. 무엇을 열면 되나요?

| 목적 | 바로가기 |
|---|---|
| 현재 사용할 지침 | [최신 AGENTS.md](../AGENTS.md) |
| 날짜별로 보관한 파일 | [2026년 10월 14일 보관 폴더](../archive/2026-10-14/README.md) |
| 피드백 반영 전 241줄 제출본 | [수정 전 파일](../archive/2026-10-14/before-feedback.md) |
| 피드백 반영 후 198줄 보관본 | [수정 후 파일](../archive/2026-10-14/after-feedback.md) |
| 분리한 교육 발상 예시 | [교육 예시](../examples/education-ideas.md) |
| 전체 변경 이력 | [커밋 기록](https://github.com/RyuJuyeon/reserch-agent/commits/main/) |
| 저장소 첫 화면 | [처음으로](../README.md) |

현재 지침은 앞으로 수정될 수 있습니다. 날짜별 폴더의 보관본은 그때의 내용을 남겨 둔 파일입니다. 이전 내용도 보관되어 있으므로 커밋 번호를 외울 필요가 없습니다.

## 2. 화면의 이름은 무슨 뜻인가요?

- **reserch-agent**: 이 프로젝트 전체를 담는 저장소 이름입니다.
- **사용안내**: 지금 읽는 안내가 들어 있는 폴더입니다.
- **archive**: 이전 파일을 날짜별로 보관하는 폴더입니다.
- **examples**: 지침에서 분리한 예시를 보관하는 폴더입니다.
- **AGENTS.md**: AI가 따라야 하는 역할과 작업 절차입니다.
- **README.md**: 해당 폴더의 설명서입니다.
- **Commits**: 저장한 변경 이력입니다.

## 3. 컴퓨터에 파일을 받으려면

[전체 파일 ZIP 내려받기](https://github.com/RyuJuyeon/reserch-agent/archive/refs/heads/main.zip)를 누르고, 내려받은 ZIP 파일의 압축을 풉니다. 이 파일은 현재 main 브랜치의 파일 묶음이며 Git 변경 이력 전체를 포함하지 않습니다. [GitHub 공식 다운로드 안내](https://docs.github.com/en/repositories/working-with-files/using-files/downloading-source-code-archives)

이 저장소의 AGENTS.md는 실행 프로그램이 아닌 지침 문서입니다. AI에게 현재 지침의 내용을 제공하고 다음과 같이 요청할 수 있습니다.

> 이 AGENTS.md의 지침에 따라 연구 아이디어를 함께 탐색해줘. 아직 주제가 없으니 내 관심사부터 질문해줘.

## 4. 앞으로 폴더를 추가하고 싶다면

이 대화에서 ‘오늘 날짜로 수정 전·후 파일을 보관해줘’ 또는 ‘새 자료를 넣을 폴더를 만들어줘’라고 요청하면 됩니다. 실제 자료와 용도에 맞춰 폴더를 추가하고 첫 화면의 링크도 갱신할 수 있습니다.

연구 중 생성하는 개인 기록의 지정 위치는 `projects/<연구명>/`이며 공개 업로드 대상에서 제외되어 있습니다. 이 공개 저장소에는 학생 개인정보나 비공개 연구 원자료를 넣지 않습니다.
