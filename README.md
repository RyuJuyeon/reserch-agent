# reserch-agent

막연한 연구 관심을 브레인스토밍으로 구체화하고 실행 가능한 연구계획서로 발전시키는 한국어 에이전트 지침입니다. 저장소 이름은 `reserch-agent`입니다.

날짜는 보관일입니다. 보관본은 해당 시점의 기록이며, 이후 수정은 루트의 `AGENTS.md`에 반영합니다.

### 주요 파일

- `AGENTS.md`: 역할, 질문 원칙, 아이디어 발상, 연구 설계, 계획서 작성 및 점검 절차.
- `README.md`: 사용법과 공개 자료 관리 안내.
- `examples/education-ideas.md`: 본문에서 분리한 교육 분야 발상 예시.
- `examples/quality-cases.md`: 본문에서 분리한 가상 행동 점검 사례.
- `.gitignore`: 지침·설명·검토된 예시만 공개 추적하도록 제한하는 규칙.
- `projects/<연구명>/idea-log.md`, `proposal.md`: 저장 요청 시 생성하는 로컬 연구 기록과 계획서. 공개 Git 추적에서 제외.

별도 스킬, 실행 프로그램, API 호출 코드가 없습니다. 이 저장소 자체에 API 키를 설정할 필요는 없습니다. 실제 대화에는 사용 중인 AI 도구의 계정과 이용 환경이 필요합니다.

## 사용법

### 프로젝트 지침으로 사용

1. 이 저장소를 내려받거나 복제합니다.
2. AGENTS.md 지침을 지원하는 에이전트에서 저장소 폴더를 작업 프로젝트로 엽니다. 또는 기존 연구 프로젝트의 루트에 `AGENTS.md`를 배치합니다. 기존 파일이 있다면 내용을 검토하여 합치고 덮어쓰지 않습니다.
3. 새 대화에서 아래 예시처럼 관심사나 아이디어를 입력합니다.
4. 에이전트 질문에 답하고 후보를 비교합니다. 관심이 가는 방향을 선택한 뒤 연구계획서 작성을 요청합니다.

Codex의 지침 검색 범위와 우선순위는 [공식 AGENTS.md 안내](https://developers.openai.com/codex/guides/agents-md)를 참고하세요. 실제 적용되는 상위 지침과 도구 환경도 함께 확인하세요.

### 프롬프트로 사용

AGENTS.md를 자동으로 읽지 않는 도구에서는 파일 내용을 대화 지침으로 제공하고 다음과 같이 요청할 수 있습니다.

> 첨부한 AGENTS.md의 절차에 따라 연구 아이디어를 함께 탐색해 주세요. 아직 주제는 정하지 않았습니다. 질문은 한 번에 1~3개씩 해 주세요.

적용 방식과 가능한 기능은 도구에 따라 달라집니다.

## 입력 예시

> 교육에서 AI를 활용하고 싶은데 논문 주제가 없습니다. 경험과 관심에서 아이디어를 찾도록 도와주세요.

> 학생이 반대 관점을 검토하고 자신의 설명을 수정하는 수행평가가 궁금합니다. 경험·과정·설계 관점으로 연구 후보를 제안해 주세요.

> 재택근무와 직무 만족의 관계를 연구하고 싶습니다. 필요한 정보를 질문하고 연구계획서로 발전시켜 주세요.

교육과정·수업·평가·수행평가·기록 등은 발상 예시입니다. 특정 교과, 학교급, AI 제품 또는 연구 방법을 강제하지 않습니다.

## 작업 흐름과 결과물

생각 발견 → 아이디어 확장 → 방향 비교·선택 → 필요한 정보 확인·설계 → 연구계획서 작성·검토.

연구계획서에는 배경, 목적, 질문, 방법, 분석, 기여·한계, 일정, 윤리·자료 관리, 문헌 검토 및 다음 행동을 포함합니다. 질문·자료·분석 연결표를 작성하며, 미정 사항은 `[가정]` 또는 `[확인 필요]`로 구분합니다.

문헌과 연구 결과를 만들지 않고, 검색 또는 제공 자료로 확인한 범위를 표시하도록 설계되어 있습니다. 실제 연구 수행, 기관 승인, 논문 심사 통과를 보장하지 않습니다. 사용자와 지도교수의 검토가 필요합니다.

## 공개 저장소에 넣지 않는 자료

API 키·토큰·비밀번호, 개인 식별정보, 학생 자료, 실제 연구 원자료, 동의서, 면담 기록, 개인 초안, 대화 기록, 논문 원문, 외부에서 받은 과제·참고 자료는 별도로 관리합니다. 허가받은 자료라도 이 공개 저장소에 자동 포함하지 않습니다.

`.gitignore`는 기본적으로 모든 파일을 제외하고 루트의 세 파일, 명시한 예시 두 파일과 날짜별 보관 파일만 허용합니다. 새 공개 파일을 추가하려면 내용을 검토한 뒤 허용 규칙을 변경해야 합니다. 이미 추적된 파일이나 Git 이력의 정보는 `.gitignore`로 제거되지 않습니다.

공개 전에는 파일 목록과 내용을 다시 확인합니다. 패턴 검색은 완전한 비밀정보·개인정보 검출을 보장하지 않습니다. 생성한 연구 기록은 Git 추적에서 제외한 `projects/<연구명>/`에 보관하고, 민감 원자료는 별도의 비공개 위치에서 관리하세요.

## 6주차 피드백 반영

- `AGENTS.md`를 241줄에서 198줄로 줄이고 교육 발상·행동 점검 사례를 `examples/`로 옮겼습니다.
- 연구별 기록 위치를 `projects/<연구명>/idea-log.md`·`proposal.md`로 명시했습니다.
- 8개 검수 항목에 각각 0·1·2점 기준을 두고 전 항목 2점을 통과 조건으로 정했습니다. 이는 계획서 자체검수 기준이며 과제의 18점 평가표와 다릅니다.
- 최초 검수 후 최대 두 차례 수정·재검수를 진행합니다. 미달이 남으면 이유·영향·대안을 제시하고 사용자 승인을 기다리며, 승인받은 잠정본도 통과본으로 표시하지 않습니다.
- 단일 에이전트 구조입니다. 멀티 에이전트 가산점 항목을 구현하거나 획득했다고 주장하지 않습니다.

## 점검 범위

이 지침은 교육 수행평가, 교육 외 관찰 연구, 참여자가 없는 이론 연구 등 가상 시나리오를 수동으로 적용해 검토했습니다. 독립 모델의 실행 성능이나 실제 연구 효과를 실증한 것은 아닙니다. 개인 맥락과 작업 기록은 공개본에서 제외했습니다.
