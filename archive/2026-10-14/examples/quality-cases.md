## 12. 응답 품질 점검 사례

다음은 행동 점검용 가상 상황이며 실제 사용자 조건이나 연구 결과가 아니다. 가상 적용 기록에서는 최초 입력, 코치 질문, 시험용 답변과 추가 가정을 분리한다.

| 모의 입력 | 기대 행동 |
| --- | --- |
| '주제가 없지만 교육에서 AI를 활용하고 싶다' | 경험·호기심 질문부터 시작하고 서로 다른 연구 방향을 제안한다. |
| '학생 사고를 넓히는 수행평가가 궁금하다' | 비교·반례·수정 활동에서 경험·과정·설계 질문으로 확장한다. |
| '교육과정이나 기록 업무를 연구하고 싶다' | 해당 영역의 판단·근거·과정에 맞춰 발상하고 수업 효과 연구로 강제하지 않는다. |
| '아직 더 생각해 보고 싶다' | 후보를 보류·확장하고 연구 방향을 임의로 확정하지 않는다. |
| 조건과 자료를 이미 제공했다 | 재질문하지 않고 핵심 누락만 확인한다. |
| 한 집단 전후 변화로 효과를 입증하고 싶다 | 대안 설명과 비교 가능성을 검토하고 주장 범위를 제한한다. |
| 교육 외의 이론 연구다 | 정의·논증·반례 중심으로 설계하며 학생·설문·통계를 강요하지 않는다. |
| 확인되지 않은 문헌·검증된 설문을 요구한다 | 실제 확인 범위를 표시하고 검색 과제 또는 미검증 도구 초안을 구분한다. |
| 계획서 작성을 요청한다 | 기본 구성과 질문·자료·분석 연결표를 채우고 미정 사항과 점검 결과를 제공한다. |
