### 교육 관심사를 활용하는 발상 예시

다음은 개인 관심을 돕는 예시이며 필수 연구 영역이나 효과가 입증된 활용법 목록이 아니다. 관련되는 2~3개만 선택한다.

| 영역 | 아이디어를 여는 질문 |
| --- | --- |
| 교육과정 | 기대하는 배움과 활동·평가는 어디에서 연결되거나 어긋날까? |
| 수업 | AI가 설명·질문·반례·대안을 제공하면 학습 과정은 어떻게 달라질까? |
| 평가 | 학생과 교사는 피드백이나 평가 기준을 어떻게 이해하고 수정할까? |
| 수행평가 | 비교·관점 전환·검증·수정 활동으로 학생 사고를 어떻게 드러낼까? |
| 생활기록부 기록 | 실제 활동·성장의 근거를 교사는 어떻게 선택하고 해석할까? |
| 참여·접근성 | 어떤 지원이 참여 장벽을 줄이고 새 어려움을 만들까? |

AI를 학생용 챗봇으로만 생각하지 않는다. 학습 지원, 교사 설계 보조, 평가·피드백 지원, 근거 정리 등을 고려한다. 교육 문제 → AI와 사람의 역할 → 알고 싶은 변화 → 필요한 근거로 연결한다. AI를 쓰지 않는 대안도 검토한다.

수행평가에 관심이 있으면 보고서·영상처럼 형식만 바꾸지 말고 학생이 할 사고를 구체화한다. '초기 해결안 → 대안·반대 관점 검토 → 조건 변화 → 수정안과 이유 설명'을 예시로 제시하고 다음처럼 연구 질문으로 확장할 수 있다.

- 학생은 반대 관점을 접한 뒤 자신의 설명을 어떻게 수정하는가?
- 교사는 어떤 수행 근거를 사고 확장으로 판단하는가?
- 이러한 수행평가의 설계 원리는 무엇이며 어떻게 보완할 수 있는가?

활동 설계 자체를 최종 목표로 삼지 않고 무엇을 연구할지 연결한다. 결과물의 외형이나 AI 출력의 유창함을 학생 사고의 단독 근거로 삼지 않는다. 기록 관련 아이디어는 실제 관찰 근거를 중심에 두며 학생의 활동·역량·성장을 만들어내지 않는다. 실제 교육과정·평가·기록 규정 적용이 필요하면 해당 연도·학교급의 공식 자료를 확인한다.
